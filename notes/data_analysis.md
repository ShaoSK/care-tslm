# A+B 数据初步分析（2026-11-18）

> 方法比较粗：只看窗口内的**平均值**。结论只用于指导设计，不代表模型最终能力。

## 方法

- 基线：每个事件文件训练段前半年、状态码 0 的点。
- 第一步：直接与基线均值比较（z = (窗口均值 − 基线均值) / 基线标准差）。
- 第二步：同工况残差。在基线上拟合 `y ≈ w0 + w1·环境温度 + w2·功率 + w3·功率² + w4·风速`（功率 > 0.05），窗口内取残差均值 / 基线残差标准差。
- 部件组按传感器描述关键词归类：gearbox / generator bearing / transformer / hydraulic / rotor bearing。表中数值为组内 |z| 最大的传感器的 z。
- 对照：正常事件做同样计算，作为"正常波动范围"。

## 发现 1：直接比较时，信号被季节淹没

几乎所有事件偏差最大的都是环境温度、机舱温度、轮毂控制器温度等，与故障部件无关。→ 必须使用同工况残差。

## 发现 2：同工况残差（故障前 3 天）

| 故障 | 事件 | 对应部件组 z | 正常事件 中位数 / 最大值 |
|---|---|---|---|
| 变压器（B） | B34 / B7 / B19 | +4.4 / +4.1 / +2.8 | 0.67 / 5.7（B2、B82 正常事件也很高） |
| 变压器（A） | A68 | +0.9 | 同上 |
| 发电机轴承 | A0 / A40 | +1.8 / 无数据（停机） | 0.58 / 2.6 |
| 齿轮箱 | A72 / A51 / A10 | +1.0 / +0.9 / +0.6 | 0.28 / 1.0 |
| 液压 | A 的 6 个事件 | 均在 ±0.3 内 | 0.24 / 0.9 |
| 主轴承 | B53 / B27 / B77 | +1.1 / −0.6 / −2.4 | 0.86 / 2.4 |

- 电气类指标（电流、无功功率、电压）在正常事件中也常偏差 3–6σ，噪声大。
- 故障前 3 天，风机平均只有 40%–90% 的时间在正常发电。

结论：
- 故障前 2 小时，18 个异常事件中有 9 个几乎没有发电数据（已停机或限功率）。
- 短窗口噪声大；**齿轮箱在 7–30 天窗口下与正常事件清晰分开**，且在标注起点之前就已偏高（可能比标注更早出现）。
- 发电机轴承、变压器 B34 是急性变化，只在故障前几天可见。
- → 采用多尺度输入：30 天（4 小时分辨率）+ 7 天（1 小时分辨率）。

### 关键问题：规则证据与标签大面积不一致

训练折上"推理文本是否点到了偏离"与标签的交叉表：

| | 有偏离证据 | 无偏离证据 |
|---|---|---|
| 标签 anomaly | 1,664（20.7%） | **6,392（79.3%）** |
| 标签 normal | 1,537（14.6%） | 9,020（85.4%） |

也就是说，把"任一部件组残差超阈值"直接当作报警（即第 8 节的残差阈值基线），在这一折的训练分布上
**逐快照召回只有 20.7%，精确率约 52%**（基线正常样本里有 14.6% 也会触发）。

两个后果：
1. 残差基线很弱 → TSLM 有明显的提升空间，但也说明"单看阈值"不足以解决这个任务；
2. 79% 的异常训练样本，其推理文本会是"没有部件超出正常范围……但整体形态仍按早期异常处理"，
   等于在教模型"没有证据也要说 anomaly"。这是标签噪声，会压低精确率，而 CARE-Score 里
   Accuracy 的权重是 2.0（最高）。**这是目前最大的设计风险**，处理方案待定（见 PLAN.md 待办）。

## 发现 5：模型的报警太零散，过不了 CARE 的检出门槛（2026-11-18，开发折 A-0）

微调后的 1B Flamingo 在测试风机 A-0 上逐小时预测 1,873 次，生成格式 100% 可解析。
混淆矩阵（快照级）：

| | 预测 anomaly | 预测 normal |
|---|---|---|
| 真实 anomaly | 102 | 573 |
| 真实 normal | 51 | 1,147 |

快照级召回只有 15.1%，但误报率只有 4.3%。放到事件层面看，**逐事件报警率的区分度很好**：

| 事件 | 标签 | 报警率 |
|---|---|---|
| A0 | anomaly | 21.7% |
| A26 | anomaly | 12.5% |
| A73 | anomaly | 3.8% |
| A24 | normal | 1.1% |
| A71 | normal | 0.5% |

异常与正常相差 20–40 倍。问题出在 CARE 的检出判据是 `criticality > 72`，
即报警要**连续约 12 小时**；模型的报警是零散脉冲，max criticality 只有 24 / 18 / 6，
三个异常事件一个都没算检出，Reliability = 0，总分归零。

对照残差阈值基线：它在 A0、A73 上报警率 100%（"一直喊狼来了"），轻松过门槛，
但在正常事件 A24 上也报警 25.6%（criticality 384）造成误报。
**两者的失败模式正好相反**：基线过度敏感、模型过度保守。

推测原因（待验证）：
1. 训练集正负比 4:1（6,988 : 1,747），先验偏向 normal；
2. 叠加发现 4 的"79% 异常样本无可见证据"，模型的最优策略就是多说 normal；
3. 逐小时独立判断，没有任何时间上的连贯性约束，所以报警天然零散。

对应三个修法见 `PLAN.md` 第 8.1 节。
